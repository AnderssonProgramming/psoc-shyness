## 📋 Descripción del Proyecto

Una aplicación web interactiva y educativa desarrollada como parte del taller de **Timidez** para la clase de Psicología Social. Este proyecto profundiza en la comprensión de la timidez desde una perspectiva psicológica, explorando sus manifestaciones conductuales, cognitivas y emocionales a través de una experiencia visual moderna y atractiva.

> **🎯 Objetivo:** Crear conciencia sobre la timidez como fenómeno social, sus características, causas y representaciones en los medios, todo presentado en una interfaz web elegante y fácil de usar.

## ✨ Características Principales

### 🎨 **Diseño Moderno e Interactivo**
- ✅ Interfaz con **gradientes vibrantes** y animaciones suaves
- ✅ **Modo oscuro/claro** con persistencia en localStorage
- ✅ Diseño **100% responsive** adaptado a todos los dispositivos
- ✅ Tarjetas interactivas con efectos hover 3D
- ✅ Transiciones fluidas y animaciones CSS

### 🧠 **Contenido Educativo Estructurado**

#### 📝 **1. Situación Cotidiana de Timidez**
Análisis detallado de un caso real de timidez en contexto universitario, incluyendo:
- 🔍 Descripción de la situación
- 🧬 Causas subyacentes
- 💫 Emociones experimentadas
- 👤 Características de la persona
- ⚠️ Consecuencias observadas

## 🛠️ Instalación y Uso

### Opción 1: Uso Directo
```bash
# Simplemente abre el archivo en tu navegador
1. Clona el repositorio
   git clone https://github.com/AnderssonProgramming/psoc-shyness.git

2. Navega al directorio
   cd psoc-shyness

3. Abre index.html en tu navegador favorito
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
```

### Opción 2: Servidor Local
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (http-server)
npx http-server -p 8000

# Luego visita: http://localhost:8000
```
